SPA built on React 19 + react-router-dom v7, bootstrapped from `src/main.tsx` which wraps the app in `<BrowserRouter>` and `<AuthProvider>`. Routing is centralized in `src/App.tsx`: public routes (`/login`, `/register`) sit alongside a nested `<Routes>` block guarded by a `RequireAuth` HOC that renders `AppShell`; per-role access is enforced via a `RequireRole` HOC (`borrower` | `lender` | `auditor`). The `lib/` layer owns cross-cutting concerns: `api.ts` is a thin fetch wrapper that holds the access token in memory, performs one-shot refresh via `/api/v1/auth/refresh`, and throws typed `ApiError`s; `auth.tsx` exposes an `AuthProvider` context plus `useAuth()` hook and the `homeFor(role)` redirect helper. Pages are grouped under `pages/{borrower,lender,auditor,auth}` with each role getting its own dashboard component, while `components/AppShell.tsx` and `components/ui.tsx` provide shared chrome and primitives. Styling uses Tailwind CSS (configured via `tailwind.config.js` + PostCSS). A PWA service worker at `public/sw.js` is registered only in production builds. Deployment is a multi-stage Dockerfile that builds the SPA with Vite and serves it through nginx, which also reverse-proxies `/api` to the backend so the browser never sees CORS or multiple origins.
