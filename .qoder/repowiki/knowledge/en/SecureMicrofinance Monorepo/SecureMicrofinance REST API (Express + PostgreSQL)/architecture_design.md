Single-process Express 5 application built in TypeScript. `src/server.ts` is the only process entry point; it calls `createApp()` from `src/app.ts`, which wires global middleware (helmet, cors, cookie-parser, request-id context, rate limiter) before mounting feature routers under `/api/v1/auth` and `/api/v1/me`. Feature code lives under `src/modules/<domain>/` (auth, users, audit, fraud, ledger), each pairing route handlers with a thin service layer that owns business logic and DB access. Cross-cutting concerns are isolated: `src/middleware/` (auth guard, validation, error handler, rate limiting, request-context propagation), `src/lib/` (crypto, cookies, canonicalization, error helpers), `src/db/` (pg pool, parameterised query helpers, transaction wrapper, migration/reset/seed scripts). Database schema evolves via numbered SQL migrations (`001_core_auth.sql` … `004_fraud_audit.sql`) applied through `src/db/migrate.ts`. OpenAPI spec at `openapi.yaml` is loaded at runtime into swagger-ui-express for `/api/docs`. Tests run against a real PostgreSQL instance (`secure_microfinance_test`) using Vitest with `fileParallelism: false` so append-only triggers and hash chains can be validated end-to-end.
