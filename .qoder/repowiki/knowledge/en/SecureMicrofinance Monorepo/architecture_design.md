The root `package.json` declares three NPM workspaces (`backend`, `frontend`, `contracts`) and is the single entry point for every lifecycle command: database boot via `scripts/dev-db.mjs` (embedded PostgreSQL on port 55432), migration/seed tasks delegated to the backend workspace, concurrent dev server orchestration via `concurrently` for API + web, and smoke tests against the running API. The three children share environment configuration through `.env.example`, which defines the contract between them — `DATABASE_URL` / `TEST_DATABASE_URL` for the backend's Postgres, `WEB_ORIGIN` / `API_BASE_URL` for CORS and client fetch targets, `CHAIN_*` variables consumed by the backend's blockchain ledger integration, and `ML_SERVICE_URL` for the optional fraud-detection service. `docker-compose.yml` mirrors this contract in production: a `postgres` service, an `api` container built from `backend/Dockerfile` that depends on Postgres health, and a `web` container built from `frontend/Dockerfile` that proxies to the API. The `contracts/` workspace is independent of the runtime stack (Hardhat) but its deploy address feeds back into the backend via `LEDGER_CONTRACT_ADDRESS`.
